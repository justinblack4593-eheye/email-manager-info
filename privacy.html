Email Manager - Privacy Policy

Last updated: November 14, 2026

Email Manager is a personal tool that runs only on its owner's own computer. It is not offered to the public.

What it accesses. With the owner's permission (Google sign-in), it reads and organizes the owner's own Gmail (sorting, labels, archiving, reply drafts) and can upload the owner's own videos to the owner's YouTube channel.

Where data goes. Email content stays on the owner's computer, except that short excerpts of incoming emails are sent to Anthropic's Claude API to sort them and draft replies. Nothing is sold, shared with advertisers, or used for any other purpose. Google sign-in tokens are stored in Windows Credential Manager on the owner's computer.

Google user data. Use of information received from Google APIs follows the Google API Services User Data Policy, including the Limited Use requirements.

Removing access. Access can be removed at any time at https://myaccount.google.com/permissions.
